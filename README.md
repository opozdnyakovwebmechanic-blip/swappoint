# SwapPoint MVP

Современный mobile-first сервис обмена вещами за внутренние баллы. MVP использует Next.js, React, TypeScript, Tailwind CSS и Prisma. Локальная БД — SQLite; для production достаточно поменять `provider` и `DATABASE_URL` на PostgreSQL.

## Запуск

1. `npm install`
2. Скопируйте `.env.example` в `.env`
3. `npx prisma generate && npx prisma db push && npx tsx prisma/seed.ts`
4. `npm run dev` и откройте http://localhost:3000

Для production-проверки: `npm run build && npm run start`.

## Структура

- `src/app` — маршруты и страницы: каталог, карта, кабинет, кошелёк, авторизация, добавление вещи.
- `src/components/app.tsx` — UI-компоненты и демонстрационные данные витрины.
- `prisma/schema.prisma` — сущности пользователей, вещей, фотографий, избранного и операций баллов.
- `prisma/seed.ts` — 10 тестовых пользователей и 30 вещей. У Анны 48 баллов.

## Демонстрационный сценарий

На странице любой вещи нажмите «Хочу получить»: заявка резервирует вещь. Кнопка «Подтвердить передачу» завершает демонстрационный обмен и показывает списание/начисление. На странице «Баллы» пакеты работают как тестовый checkout и мгновенно увеличивают баланс. В этой ранней UI-версии состояние обмена/кошелька живёт в браузере; схема БД подготовлена для переноса операций в API routes.

## Что потребуется для production

Подключить PostgreSQL, Auth.js credentials/OAuth и защищённые server actions, S3/Cloudinary для загрузки фото, настоящую Leaflet-карту с геокодингом, Stripe/YooKassa, email/push, модерацию, rate limits и тесты транзакций обмена. Точные адреса намеренно не отображаются публично — только район.
